# AI-Recommendation-System
## Collaborative Filtering using MovieLens 100k

---

## Overview
This project implements an end-to-end collaborative filtering recommendation system using the MovieLens 100k dataset. The objective is to model user–item interactions, reduce sparsity through preprocessing, train a matrix factorization model, and generate personalized movie recommendations.

The workflow follows a complete machine learning pipeline:

**data exploration → preprocessing → baseline modeling → hyperparameter tuning → evaluation → Top-N recommendations → model comparison → ethical & deployment analysis**

---

## Dataset
**MovieLens 100k**

- 100,000 ratings  
- 943 users  
- 1,682 movies  
- Rating scale: 1–5  

The dataset is loaded into pandas and converted into a Surprise-compatible format for collaborative filtering.

---

## Methods

### Data Preprocessing
- Remove duplicates and missing values
- Verify data types
- Drop timestamp column
- Filter extremely inactive users/items (minimum ratings threshold)
- Reduce sparsity to improve model stability
- Analyze rating distributions and interaction patterns

### Modeling
- Train/test split (75% / 25%)
- Collaborative filtering using **Singular Value Decomposition (SVD)**
- Baseline model training
- Hyperparameter tuning with **GridSearchCV (3-fold cross-validation)**
- Expanded grid search for deeper optimization
- Final retraining with best parameters
- Generate **Top-N personalized recommendations**

### Evaluation Metrics
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- Residual analysis
- Algorithm comparison (SVD, SVD++, KNNBaseline, NMF)

### Libraries
- pandas  
- numpy  
- matplotlib / seaborn  
- scikit-learn  
- surprise (scikit-surprise)

## Results

### Performance Improvements
| Stage | RMSE | MAE |
|-------|--------|--------|
| Baseline SVD | 0.948 | — |
| After sparsity filtering | 0.936 | — |
| Grid Search v1 (CV best) | 0.9266 | — |
| Grid Search v2 (CV best) | 0.9198 | 0.7270 |
| **Final tuned model (test)** | **0.9071** | **0.7173** |

Systematic preprocessing and hyperparameter tuning reduced prediction error by **~4–5%** compared to baseline.

---

### Algorithm Comparison
| Model | RMSE | MAE |
|---------|---------|---------|
| **SVD (tuned)** | **0.918** | **0.726** |
| SVD++ | 0.926 | 0.728 |
| KNNBaseline | 0.936 | 0.738 |
| NMF | 0.971 | 0.763 |

Tuned SVD achieved the best trade-off between accuracy and efficiency.

## Key Takeaways

- Matrix factorization (SVD) effectively handles sparse user–item rating data  
- Filtering extremely inactive users/items improves model stability  
- Hyperparameter tuning significantly reduces prediction error  
- Tuned SVD outperforms alternative collaborative filtering methods (SVD++, KNNBaseline, NMF)  
- Ethical considerations (bias, fairness, privacy, transparency) are essential for responsible deployment
